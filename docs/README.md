# PDF RAG 프로젝트

PDF 문서를 기반으로 한 RAG (Retrieval-Augmented Generation) 시스템입니다. Ollama를 사용하여 로컬에서 실행 가능한 PDF 질의응답 시스템을 제공합니다.

## 📋 프로젝트 개요

이 프로젝트는 PDF 문서를 업로드하고, 문서 내용에 기반하여 질문에 답변하는 시스템입니다. LangChain과 ChromaDB를 사용하여 벡터 검색을 구현하고, Ollama의 LLaMA 모델을 사용하여 답변을 생성합니다.

## 🚀 주요 기능

### 기본 버전 (`Ollama_PDF_RAG.py`)
- PDF 파일 업로드 및 텍스트 추출
- 문서 청킹 및 벡터화
- ChromaDB를 사용한 벡터 저장
- LLaMA 3 모델을 사용한 질의응답
- Gradio 웹 인터페이스

### 개선 버전 (`Ollama_PDF_RAG_improved.py`) ✨
- **파일 해시 기반 캐시 시스템**: 동일한 PDF는 재처리하지 않고 캐시에서 재사용
- **검색 파라미터 조정**: 검색 결과 개수(k) 조정 가능
- **모델 선택**: LLM 모델 및 임베딩 모델 선택 가능
- **향상된 에러 처리**: 구체적인 에러 메시지 및 로깅
- **처리 정보 표시**: 로드 시간, 검색 시간, 생성 시간 등 상세 정보 제공
- **캐시 관리**: 캐시된 파일 목록 확인 및 삭제 기능
- **클래스 기반 구조**: 유지보수성 향상

## 📦 설치 방법

### 1. 필수 요구사항
- Python 3.8 이상
- Ollama 설치 및 실행 중
- 필요한 모델 다운로드:
  - LLM 모델: `llama3` (또는 다른 지원 모델)
  - 임베딩 모델: `mxbai-embed-large`

### 2. Ollama 모델 설치
```bash
# LLM 모델 설치
ollama pull llama3

# 임베딩 모델 설치
ollama pull mxbai-embed-large
```

### 3. Python 패키지 설치
```bash
pip install -r config/requirement.txt
```

## 🎯 사용 방법

### 기본 버전 실행
```bash
python scripts/Ollama_PDF_RAG.py
```

### 개선 버전 실행 (권장)
```bash
python scripts/Ollama_PDF_RAG_improved.py
```

실행 후 브라우저에서 `http://localhost:7860`으로 접속하세요.

### 사용 단계
1. PDF 파일 업로드
2. 질문 입력
3. (개선 버전) 고급 설정에서 모델 및 검색 파라미터 조정
4. "질문하기" 버튼 클릭
5. 답변 확인

```
PDF_RAG/

│   └── [PDF 파일들]                # 테스트용 PDF 문서들

│   └── README.md                   # 프로젝트 문서

│   └── requirement.txt             # 의존성 패키지 목록
└── chroma_pdf_cache/               # ChromaDB 벡터 캐시 디렉토리
    ├── chroma.sqlite3              # 벡터 데이터베이스
    ├── cache_metadata.json         # 캐시 메타데이터 (개선 버전)
    └── [해시 폴더들]               # 벡터 인덱스 파일들
```

## 🔧 주요 클래스 및 함수

### 개선 버전 구조

#### `Config` 클래스
설정값을 관리하는 클래스입니다.
- 캐시 디렉토리 경로
- 기본 모델명
- 청크 크기 및 오버랩
- 검색 파라미터 기본값

#### `CacheManager` 클래스
캐시 관리를 담당하는 클래스입니다.
- 파일 해시 계산
- 캐시 존재 여부 확인
- 캐시 정보 저장/로드
- 캐시 삭제

#### `PDFRAGSystem` 클래스
메인 RAG 시스템 클래스입니다.
- PDF 로드 및 벡터화
- 문서 검색
- 답변 생성
- 전체 RAG 파이프라인 실행

## ⚙️ 설정 옵션

### 개선 버전 고급 설정

- **LLM 모델**: 사용할 언어 모델 선택 (llama3, llama3.1, llama3.2, mistral, qwen2)
- **임베딩 모델**: 사용할 임베딩 모델 선택 (mxbai-embed-large, nomic-embed-text)
- **검색 결과 개수 (k)**: 검색할 문서 청크의 개수 (1-10)
- **캐시 사용**: 이전에 처리한 PDF를 캐시에서 재사용할지 여부

## 🐛 문제 해결

### Ollama 연결 오류
- Ollama가 실행 중인지 확인: `ollama list`
- 모델이 설치되어 있는지 확인: `ollama list`

### PDF 텍스트 추출 실패
- PDF가 텍스트 기반인지 확인 (이미지만 있는 PDF는 처리 불가)
- 다른 PDF 파일로 시도

### 캐시 문제
- 캐시를 삭제하고 다시 시도: 개선 버전의 "캐시 모두 삭제" 버튼 사용
- `chroma_pdf_cache` 디렉토리 삭제 후 재시작
